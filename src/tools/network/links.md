# links: web in a text console

**Package:** `links`

```sh
links https://voidlinux.org      # browse in the terminal (arrows, Enter; q quits)
links /usr/share/doc/d77orphaned/html/index.html   # this documentation, offline
```

Works without a graphical session. `d77-docs` opens this documentation in
links on a console, or in Mullvad Browser in a graphical session.
