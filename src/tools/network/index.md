# Network

Tools to connect, diagnose a network, transfer data and look at traffic.
For getting online in the first place, see [Network](../../network/index.md).

The scanning and capture tools ([nmap](nmap.md), [tcpdump](tcpdump.md),
[arp-scan](arp-scan.md)) are for networks you are **authorized** to test.

| Tool | For |
|---|---|
| [nmcli and nmtui](networkmanager.md) | connecting to wired and Wi-Fi networks |
| [ip](ip.md) | addresses, routes, interfaces |
| [ping, traceroute, mtr](ping.md) | reachability and the path to a host |
| [dig, host, whois](dns.md) | DNS and domain ownership |
| [iw and ethtool](link.md) | Wi-Fi and Ethernet link details |
| [curl, wget, lftp](transfer.md) | downloading and uploading |
| [ssh, scp, rsync, sshfs](ssh.md) | remote shells, copying, mounting over SSH |
| [NFS and SMB shares](shares.md) | mounting network shares |
| [tcpdump](tcpdump.md) | capturing traffic |
| [nmap](nmap.md) | finding hosts and open ports |
| [testssl.sh](testssl.md), [ssh-audit](ssh-audit.md) | auditing TLS and SSH servers |
| [arp-scan](arp-scan.md) | listing devices on the local network |
| [nc and socat](nc.md) | raw connections, quick file transfer |
| [iperf3](iperf3.md) | measuring bandwidth |
| [iftop and nethogs](monitor.md) | who is using the network |
| [WireGuard and OpenVPN](vpn.md) | VPN connections |
| [links](links.md) | web browsing in a text console |
| [ipcalc](ipcalc.md) | subnet calculations |
