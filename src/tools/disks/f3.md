# f3: fake-capacity USB sticks and cards

**Package:** `f3` · **Writes to disks:** yes

Checks whether a USB stick or memory card really has the capacity it claims.

```sh
sudo f3probe /dev/sdX          # quick probe of the whole device
f3write /mnt/stick && f3read /mnt/stick   # fill a mounted stick with test files, then check them
```

> **Writes:** `f3probe` writes to the device during the test and puts the
> original blocks back afterwards (with `--destructive` it does not).
> `f3write` fills the free space with files. Use them only on a stick whose
> contents you do not need, never on evidence.
