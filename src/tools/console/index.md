# Console

Everyday tools for working in a terminal, also on the text console and in
the console-only boot.

| Tool | For |
|---|---|
| [mc and ranger](files.md) | file managers in the terminal |
| [tmux and screen](tmux.md) | several shells in one terminal; keeping jobs alive |
| [htop, iotop, iostat](processes.md) | processes, disk activity |
| [ncdu and tree](space.md) | what takes up space |
| [lsof, strace, ltrace](debug.md) | open files, what a program is doing |
| [pv and mbuffer](pv.md) | progress and buffering in pipes |
| [Archives](archives.md) | tar, zip, 7z, zstd, cabextract, unp |
| [gpg](gpg.md) | checking signatures, encrypting files |
| [minicom and tio](serial.md) | serial consoles (routers, switches, boards) |
