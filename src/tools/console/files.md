# mc and ranger: file managers

**Packages:** `mc`, `ranger`

```sh
mc           # Midnight Commander: two panels; F5 copy, F6 move, F3 view, F4 edit, F10 quit
ranger       # three columns with previews; arrows or h/j/k/l, q quits
```

In `mc`, copying a large folder (F5) shows progress and can be put in the
background. Its viewer (F3) has a hex mode (F4 inside the viewer), and it
can browse inside archives and over SFTP (Left/Right menu → "SFTP link").
`mcedit file` is its editor.
