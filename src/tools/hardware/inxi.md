# inxi: machine summary

**Package:** `inxi` · **Writes to disks:** no

```sh
inxi -b          # basic: system, CPU, machine, battery, graphics, network, drives
inxi -e          # expanded: adds audio, partitions, sensors, repositories, …
inxi -v 7        # the most detailed report
inxi -e -z       # hide serial numbers, IP and MAC addresses (for sharing the output)
```
