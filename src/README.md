# d77orphaned Docs

This is the community documentation of **d77orphaned**: a Void Linux live
system for recovery, diagnostics and careful forensics, with a small set of
tools for authorized security testing. It boots from a USB stick or DVD,
runs entirely from memory and the stick, and does not change the disks of
the computer it runs on unless you ask it to.

The model is closer to Grml than to Kali: a toolbox for when a system will
not boot, a disk is failing or you need to look at data without changing it.

> **Prototype.** d77orphaned is a proof of concept. It has been tested in
> virtual machines (QEMU, BIOS and UEFI). Tests on real hardware are still to
> do; each page says what has and has not been verified.
